- R9 当前只有 Audit Diff / Decision / Repair Executor 核心能力；尚无 durable audit job、人工触发、report-only production path 与恢复门禁。
- R10 已有 foundation 代码，但真实 Provider delta/cursor 能力尚不存在；继续接 Scheduler/production 会违反 §47 的阶段门禁。
