# CloudSite 长期运行与故障恢复

本文适用于 CloudSite 0.3.0。任何恢复操作前先停止容器，并复制当前 `data/` 和 `.env` 到其他目录。

## 数据职责

- `data/state.db`：用户、Session、AList 加密凭据、站点配置、合集、分享和操作日志。它是不可由网盘重新生成的实例身份数据。
- `data/index.db`：Folder、Resource、搜索索引和 Rolling Cycle 进度。它可以在保留 `state.db` 的前提下重建。
- `data/office-cache/`：Office 预览缓存，可删除后重新生成。

不要执行 `docker compose down -v`，不要用空的 `state.db` 覆盖旧实例，也不要用首次同步作为 `state.db` 恢复手段。

## 日常维护

服务每 6 小时清理一次过期数据：已过期或已撤销超过 7 天的 Session，以及超过 24 小时且不处于封禁期的下载限流记录。有效 Session 不会被删除，Session 活跃时间最多每 5 分钟写入一次。

OperationLog 在 0.3.0 暂不自动删除。建议安全和管理日志保留 180 天，普通运行日志保留 30～90 天，并定期观察：

```bash
docker compose exec api python - <<'PY'
import sqlite3
c = sqlite3.connect('/app/data/state.db')
print('operation_logs:', c.execute('select count(*) from operation_logs').fetchone()[0])
print('user_sessions:', c.execute('select count(*) from user_sessions').fetchone()[0])
PY
du -h data/state.db data/index.db
```

## 备份与验证

```bash
bash scripts/backup.sh
bash scripts/verify-backup.sh cloudsite-backup-YYYYMMDD-HHMMSS.tar.gz
```

备份包含密钥和 AList 加密凭据，应复制到不同磁盘或主机并按敏感文件保护。至少定期做一次恢复到临时目录的演练，不能只确认压缩包存在。

## state.db 恢复

启动检查出现 `STATE_RECOVERY_REQUIRED` 时，不要继续初始化或第一次同步。先找到最后一个通过校验的备份：

```bash
docker compose down
bash scripts/restore.sh cloudsite-backup-YYYYMMDD-HHMMSS.tar.gz --force
docker compose up -d --wait
curl -f http://127.0.0.1:3000/api/health
```

恢复后检查用户仍存在、AList 设置可读取、合集和分享未丢失，再检查索引与 Rolling 状态。

## index.db 恢复

`index.db` 缺失时，CloudSite 保留 `state.db` 并进入 `INDEX_RECOVERY`。不要删除 `state.db`，也不要伪造首次同步完成标记。优先恢复完整备份；确实只恢复索引时，由后台恢复流程重新建立 Folder、Resource 和 FTS，完成前内容接口可能暂不可用。

FTS 更新中断会留下 dirty 标记。下次启动直接从现有 active Folder/Resource 重建 FTS，不请求 AList；成功后自动清除标记。

## AList 断线与同步熔断

AList 离线时下载和预览返回明确的 `DL-*` / `PV-*` 错误，不暴露凭据、内部路径或上游异常文本。AList 恢复后下一次请求可直接恢复，无需重启 CloudSite。

Rolling 同步遇到 405、429、WAF 或访问限制时停止当前 Window 并打开熔断。未完成目录保持 pending，冷却结束或管理员确认上游恢复后继续，不重复已完成目录。

## 升级与回滚

升级 0.2.1 → 0.2.2 前必须执行并验证备份。0.2.2 迁移只补齐 Schema 和索引，不清空 User，也不重置正在运行的 Rolling Cycle。升级到 0.3.0 还会保留全部既有 Resource ID，并在首次 Stable ID 迁移前创建一次 SQLite 一致性快照。回滚镜像与数据库恢复步骤见 [`部署升级与备份.md`](部署升级与备份.md)。
